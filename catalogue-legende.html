Légende = texte après le dernier tiret avant l’extension. Les tirets entre deux majuscules dans la légende sont normalisés en tiret cadratin dans le nom de fichier. Préfixes OFF- / VAL- = non publié / à valider. PHOTO- = prise de vue à refaire. Le navigateur ne peut pas renommer les fichiers sur le disque : enregistrez renames-catalogue.sh à la racine du dépôt (pas dans Téléchargements), rendez-le exécutable (chmod +x renames-catalogue.sh), puis lancez ./renames-catalogue.sh. Ensuite remplacez media/works.json par le fichier exporté.
